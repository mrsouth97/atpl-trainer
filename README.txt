ATPL Exam Trainer - PWA cho iPad

Nội dung: 7,266 câu, 13 môn, 695 câu có hình từ các bộ đề trước.
Đã bổ sung:
- Mass & Balance: 300 câu (số gốc 1-300)
- Operational Procedures: 501 câu (số gốc 1-501)

CÁCH CẬP NHẬT REPOSITORY GITHUB PAGES HIỆN TẠI
1. Giải nén ZIP này.
2. Mở repository atpl-trainer trong GitHub Desktop -> Show in Finder.
3. Thay các file cũ bằng toàn bộ file trong ZIP (index.html phải ở root).
4. Commit -> Push origin.
5. Trên iPad, mở lại URL GitHub Pages bằng Safari khi có mạng và chờ 'Offline ready'.
6. Sau đó app Home Screen sẽ dùng được offline với bộ 13 môn.

LƯU Ý
- Tiến độ/câu sai cũ vẫn dùng cùng localStorage nên được giữ lại khi cập nhật tại cùng URL.
- Hai PDF mới là text-only; không có raster image hay vector drawing trong source PDF, nên không có hình nguồn bị bỏ sót.
