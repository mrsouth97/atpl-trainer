ATPL Exam Trainer — PWA cho iPad

Nội dung: 6465 câu, 11 môn, 695 câu có hình.
Đã bổ sung POF — Principles of Flight: 487 câu có answer key. Số câu gốc 1–500 được giữ nguyên; source không có 275–286 và 477.

CÁCH DÙNG VỚI GITHUB PAGES
1. Giải nén ZIP.
2. Chép toàn bộ các file trong thư mục gốc vào repository GitHub Pages (index.html phải ở root).
3. Commit + push bằng GitHub Desktop/Git.
4. Trên iPad mở URL HTTPS bằng Safari.
5. Chờ trạng thái “Offline ready”.
6. Chia sẻ → Thêm vào Màn hình chính → bật “Mở dưới dạng ứng dụng web” → Thêm.

LƯU Ý
- Không mở index.html trực tiếp từ app Files; offline PWA/service worker cần HTTPS.
- Giữ nguyên tất cả file trong cùng thư mục.
- Tiến độ/câu sai cũ của bản 10 môn vẫn dùng cùng localStorage, nên khi cập nhật cùng URL GitHub Pages sẽ không bị xoá chỉ vì thêm POF.
